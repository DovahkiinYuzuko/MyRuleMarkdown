🌟 これは何？
noteからエクスポートしたXMLファイルを、AI（LLM）が最も理解しやすいMarkdown形式（.md）に一括変換するツールです。
100記事以上あっても大丈夫！これ1本で、あなたのこれまでの思考や経験を凝縮した「自分自身の解説書」のソースが完成します。

🚀 使い方
noteの設定画面から「記事の書き出し（XML）」をダウンロードする。

このツールにXMLファイルをポイッと入れる。

変換された .md ファイルを保存する。

NotebookLMやChatGPTに読み込ませて、あなた専用のAIパートナーを作ろう！

💡 AI（LLM）への活用プロンプト例
これをコピペしてAIに渡すと、より精度の高い「自分解析」ができるようになるよ！

【ChatGPT / Gemini などのチャットAI向け】
以下のテキストは、私が執筆したnote記事を1つにまとめたものです。
あなたに私の価値観、思考のクセ、専門知識、文章のスタイルを学習してほしいです。
まずは内容を精査・確認し、私がどのような人物であるか分析の概要を提示してください。
以降、私は「私自身の分身」としてあなたに相談をします。

【NotebookLM 向け】
ソースとしてファイルを読み込ませた後、以下の「メモ」を固定しておくと便利！

このソースは、私が執筆したnoteの記事群です。目的は「私自身の思考のバックアップ」および「客観的な自分分析」です。
質問に答える際は、必ずこのソースの内容を最優先し、私の過去の経験や言葉に基づいた回答を生成してください。
